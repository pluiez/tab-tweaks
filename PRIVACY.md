# Tab Tweaks 隐私政策 / Privacy Policy

最后更新 / Last updated: 2026-10-05

## 中文

Tab Tweaks 不收集、不存储、不传输任何个人信息或浏览数据。

- **读取什么**：只读取浏览器提供的标签页编号、位置、是否为当前标签、由哪个标签页打开，用来决定关闭标签后焦点落在哪里、新标签放在哪里。不读取网址、标题或网页内容。
- **保存什么**：各窗口的标签页顺序只保存在浏览器内存中（`chrome.storage.session`），浏览器退出即清除，不写入磁盘，不同步到任何账号。
- **发送什么**：什么都不发送。扩展不发起任何网络请求，不包含统计、广告或任何第三方代码。

如有疑问，请通过扩展商店页面上的开发者联系方式联系。

## English

Tab Tweaks does not collect, store or transmit any personal information or browsing data.

- **What it reads**: only the tab ids, positions, active state and opener that the browser provides, to decide which tab gets focus after a close and where a new tab goes. It never reads page addresses, titles or content.
- **What it stores**: each window's tab order, kept in the browser's memory only (`chrome.storage.session`). It is cleared when the browser exits, never written to disk and never synced to any account.
- **What it sends**: nothing. The extension makes no network requests and contains no analytics, ads or third-party code.

Questions: please use the developer contact shown on the extension's store page.
